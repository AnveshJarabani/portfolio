Architecture Overview

A 5-layer architecture that separates concerns cleanly: the warehouse handles storage and compute, a semantic layer governs business logic and caching, and multiple consumers — from dashboards to AI agents — query through a single governed interface.

Cube.js Semantic Layer

7 data model cubes with multi-tenant security, pre-aggregations, and automatic refresh. The semantic layer sits between the warehouse and all consumers, ensuring every dashboard and AI agent queries through governed, cached business logic.

Multi-Tenant Security: Every query is scoped via contextToAppId (partitions cache by organization) and queryRewrite (auto-appends WHERE organization_path LIKE '{org_path}%'). A clinic sees only its data; a regional office sees all clinics beneath it. Zero trust boundary — applied at the semantic layer before any query reaches BigQuery.

Pre-aggregation strategy: High-frequency cubes like Patients use daily-granularity pre-aggregations with 15-minute refresh intervals, stored in Cube Store's columnar Parquet format. This gives sub-second dashboard loads while keeping data within minutes of the source.

Superset BI Engine

Apache Superset 4.1.1 with Okta OIDC, embedded dashboards, Celery async, and Redis caching.

🔐 Authentication
  • Okta OIDC via Flask-AppBuilder AUTH_OAUTH
  • Custom TenantSecurityManager for RLS
  • Auto-provisions users with org mapping from JWT claims
  • Roles synced from OIDC groups
🗄️ Data Sources
  • Primary: Cube.js SQL API (port 15432)
  • Fast cache: DuckDB (local Parquet via httpfs)
  • Power users: BigQuery direct (sqlalchemy-bigquery)
🚩 Feature Flags
  • EMBEDDED_SUPERSET — iframe embedding
  • ALERT_REPORTS — threshold-based alerts
  • DASHBOARD_RBAC — role-based dashboard access
  • ENABLE_TEMPLATE_PROCESSING — Jinja in SQL
⚡ Caching (Redis)
  • DB 2: General cache (5-min TTL)
  • DB 3: Data query cache (10-min TTL)
  • DB 4: Filter state cache (10-min TTL)
⚙️ Async / Celery
  • Workers with Redis DB 5 as broker
  • Results stored in Redis DB 6
  • Beat scheduler: reports every 60s check interval
  • Async queries for long-running analytics
📊 Embedding
  • Guest tokens with 1-hour expiry
  • CORS enabled for application origin
  • Talisman CSP disabled for iframe compatibility
  • @superset-ui/embedded-sdk React integration
🔍 SQL Lab

  • Role-gated access for power users
Row-Level Security

RLS enforcement at every layer — organization_path flows through the entire stack, from identity provider to warehouse.

1
Identity Provider (Okta)
JWT contains organization_path claim (e.g., /acme/northeast/boston). Issued at login via OIDC Authorization Code + PKCE flow.
2
Cube.js Semantic Layer
queryRewrite() auto-appends WHERE organization_path LIKE '{org_path}%' to every query. contextToAppId() isolates cache per tenant by appending org_path to the cache key.
3
Apache Superset
TenantSecurityManager (custom Flask-AppBuilder subclass) maps Okta groups to Superset roles and injects RLS WHERE clause per embed via guest tokens.
4
BigQuery
Views filtered by organization_path. CDC replicates full tables from the primary database, but all queries are scoped by org_path at higher layers.
5
AI Agents (ADK)
ADK agent receives organization_path from JWT, passes to BigQueryToolset as a filter parameter. All NLQ-generated SQL is scoped to the tenant.
Hierarchical paths: /acme sees all branches; /acme/northeast sees only northeast clinics beneath it.
Cache isolation: Cube.js appends org_path to the cache key so tenants never see each other's cached data.
Audit trail: Every query logs user, org_path, and timestamp for compliance traceability.

Embedded Dashboard Flow

SSO-gated embedding: no separate Superset login, RLS from JWT claims, seamless iframe integration.

1
User
Logs into the application via Okta OIDC Authorization Code + PKCE flow
2
User
Navigates to the Reports page in the React frontend
3
React Frontend
Calls backend POST /api/v1/reporting/superset-token with the user's JWT bearer token
4
Backend API
Extracts org claims from JWT, calls Superset POST /security/guest_token with RLS rules: organization_path LIKE '{org}%'
5
React Frontend
Renders dashboard using embedDashboard() from @superset-ui/embedded-sdk with the guest token
6
Superset
Serves the dashboard filtered by organization_path — no separate login required
